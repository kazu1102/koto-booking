# 鍼灸整体院 琴 予約サイト（Next.js + Supabase）

## 起動
1. Node.js LTSをインストール
2. このフォルダで `npm install`
3. `.env.example` を `.env.local` にコピーし、SupabaseのURLとanon keyを設定
4. Supabase SQL Editorで `supabase/schema.sql` を実行
5. `npm run dev` → http://localhost:3000

## 公開前の必須作業
- Supabaseの予約管理画面に管理者認証を実装し、院側2名だけに閲覧・変更権限を与える。
- 予約一覧・キャンセル・休業日設定のスタッフ画面を実装する（このパッケージでは患者向け予約フローが実装済み）。
- 本番用のメール/SMS通知、個人情報保護方針、バックアップ、アクセス制限、ログ監視を設定する。
- SupabaseのRLS/関数権限を公開前にセキュリティレビューする。
- テスト予約を使ってタイムゾーン、同時予約、キャンセル等を検証する。

## 注意
このプロジェクトは実装の土台です。Supabaseプロジェクトと環境変数を設定するまでは動作しません。管理者用画面・認証・キャンセル機能はまだ含まれません。実患者の個人情報を入力しないでください。
